# 👁️ Assistente de Visão Independente

Este é um programa web focado em **acessibilidade visual**, desenvolvido com HTML, CSS e JavaScript puros. O objetivo do sistema é garantir total autonomia para usuários com baixa visão ou cegueira ao interagir com interfaces digitais, seguindo as diretrizes de acessibilidade do W3C (WCAG).

---

## 🚀 Recursos de Acessibilidade Implementados

* **🎙️ Ditado por Voz (Speech-to-Text):** Permite preencher campos de texto falando diretamente no microfone (usando a Web Speech API).
* **🔊 Sintetizador de Voz (Text-to-Speech):** Lê em voz alta os resultados do sistema e as interações na tela.
* **⚠️ Validador de Voz Inteligente:** Caso o usuário tente enviar um campo vazio, o sistema bloqueia a ação, avisa o erro por áudio e joga o foco do teclado de volta para o campo correto.
* **🌗 Alto Contraste:** Alterna para um tema escuro estrito com textos em amarelo neon para máxima legibilidade.
* **🔍 Redimensionamento Dinâmico:** Botões para aumentar ou diminuir as fontes sem quebrar o layout da página.
* **⌨️ Navegação por Teclado:** Foco visual altamente perceptível (rosa choque) para usuários que utilizam apenas a tecla `Tab`.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica e atributos de acessibilidade (ARIA).
* **CSS3:** Variáveis de ambiente para alto contraste e layouts responsivos em unidades `rem`.
* **JavaScript (Vanilla):** Lógica do validador, Web Speech API e manipulação do DOM.

---

## 💻 Como Executar o Projeto

1. Faça o download ou clone este repositório.
2. Abra o arquivo `index.html` em qualquer navegador moderno (Google Chrome, Microsoft Edge, etc.).
3. Certifique-se de dar permissão ao uso do microfone para testar o ditado por voz.
